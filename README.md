## Requirements
Install dependencies using:

```bash
pip install -r requirements.txt
```

## How to Run
Run the Python scripts from their respective task folders:

```bash
py task1_cleaning.py
py task2_eda.py
py task3_visualizations.py
```

Open the Jupyter notebooks to view the analysis and visualizations.

## Dataset
IBM HR Analytics Employee Attrition dataset.

Place the CSV file in the appropriate task folder before running the scripts or notebooks. The raw dataset is not included in this repository.
