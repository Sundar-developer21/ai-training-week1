# Employee Attrition Data Analysis

## Project Overview
This project focuses on analyzing employee data using Python and Pandas to understand employee attrition patterns.

## Dataset
- Dataset: IBM HR Analytics Employee Attrition
- Total Records: 1,470
- Total Columns: 35
- Missing Values: 0
- Duplicate Records: 0

## Tools and Technologies
- Python
- Pandas
- Jupyter Notebook
- VS Code
- Git and GitHub

## Data Analysis Performed
- Dataset shape
- Dataset information using info()
- Statistical summary using describe()
- Missing value analysis
- Duplicate record analysis

## Business Questions
1. Which department has the highest employee attrition?
2. Does working overtime affect employee attrition?
3. Which job roles have the highest employee attrition rate?
4. Is monthly income different between employees who leave and employees who stay?
5. How do job satisfaction and work-life balance relate to employee attrition?
